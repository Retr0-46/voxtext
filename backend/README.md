# Voxtext backend

Инструкции по запуску, настройке PostgreSQL, моделям, API и остановке приложения находятся в [README проекта](../README.md).

Go-команды выполняются из этого каталога (`backend/`). На Windows перед `go run ./cmd/api` добавьте `internal/modules/voxtext` в `PATH`, как показано в корневом README.
